# Architecture Decision Records

Architecture decisions that change ownership, persistence, external side effects, public contracts or execution boundaries must be recorded here before implementation is considered complete.

## Decisions

- [ADR-0001: Layer ownership and dependency direction](0001-layer-ownership-and-dependency-direction.md)
- [ADR-0002: Durable compensation for managed project creation](0002-managed-project-creation-compensation.md)
- [ADR-0003: Cursor-paged Console read models](0003-console-read-model-pagination.md)

## Status vocabulary

- `Proposed`: under review.
- `Accepted`: active architecture rule.
- `Superseded`: replaced by a newer ADR, which must be linked.
- `Deprecated`: retained only for compatibility and must not receive new dependencies.
